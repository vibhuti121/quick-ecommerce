# 🎮 Scaling Quest — read me first

A gamified, hands-on systems-design bootcamp run against the live `quick-ecommerce` stack,
framed for a Google/Meta-tier team-lead interview loop.

## Read-order rule (keeps sessions short, avoids context explosion)
1. **`PROGRESS.md` — read FIRST, always.** The `▶ CURRENT STATE` block is self-sufficient:
   current level, exact resume point, open doubts, next action, and the boot command.
   **Do NOT re-read the conversation transcript to resume.**
2. **`CURRICULUM.md`** — read only to pick/preview the next level (the whole plan + teaching contract).
3. **A level's loot file** (`baseline.md`, `cheatsheet-level0.md`, `run-assassination-k6.txt`,
   future `cheatsheet-levelN.md`) — read only when actually working that level.

To resume in any session, just say **"resume scaling quest"**.

## At the end of every session
Rewrite the `▶ CURRENT STATE` block in `PROGRESS.md` and append one short entry to its session
log. That single update is what lets the next session start lean.

## File map
| File | What it is | Read when |
|---|---|---|
| `PROGRESS.md` | single source of truth: current state + session log | every resume, first |
| `CURRICULUM.md` | the whole plan: level ladder + teaching contract | choosing next level |
| `baseline.md` | L0 baseline numbers + incident log | working L0 |
| `cheatsheet-level0.md` | L0 concepts cheatsheet | working L0 |
