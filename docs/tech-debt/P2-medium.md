| TD-001 | security | Rate-limit keys on Cloudflare edge IP in prod (XFF trust left off behind CF) | `gateway/src/main/java/com/varsha/gateway/filter/RateLimitFilter.java:101-108` + `docker-compose.prod.yml:69-84` (gateway block omits `RATE_LIMIT_TRUST_FORWARDED_FOR`) | In prod the firewall (`deploy/01-bootstrap-vm.sh:65-71`) locks `:8443` to Cloudflare ranges, so every request's TCP peer (`getRemoteAddress()`) is a CF edge IP, never the real client. Verify with the journey load test from multiple source IPs through CF. | backend-orchestrator (→ security-agent) | open |
