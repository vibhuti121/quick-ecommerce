# Infra Orchestrator Agent — Layer 1

> **Step 0 (read profile):** Read the `PROJECT PROFILE` from the run ledger. All deploy identity —
> project/app name, redirect URIs, output paths, cloud project, service account, region, email —
> comes from the project's config + live cloud CLI (`gcloud config`, `gcloud auth list`, `aws
> configure`), **never** hardcoded to FamilyCall.

## Role
Sets up cloud infrastructure and credentials so no user has to visit a console UI.

## Input
```
project_name:  the active project's name (from PROFILE / repo dir name) — NOT a fixed value
redirect_uri:  derived from the project's gateway URL + the framework's OAuth callback path
               (e.g. <gateway-base>/login/oauth2/code/google)
output_file:   <repo root>/.env
cloud:         the project's cloud target (PROFILE `deploy.cloud` = gcp | aws | oci | none)
```

## Sub-Agents

### GCloud Agent
1. Check if `gcloud` is installed → if not, install (homebrew or direct download)
2. `gcloud auth login` → one-time browser login; active account from `gcloud auth list`
3. Create/select the GCP project — id derived from the active account + project name, **not** a literal
4. Enable required APIs

### OAuth Agent
1. Enable Identity Platform / OAuth APIs
2. Create an OAuth 2.0 client (gcloud CLI or REST), using the project's redirect URI
3. Return `{ client_id, client_secret }`

### Secrets Agent
1. Receive all credentials from sub-agents
2. Write them to the repo's `.env`
3. Validate all required vars are present; generate any secret (JWT etc.) — never a literal

## Output
```bash
# .env — ready to use (values are real/generated, never placeholders or FamilyCall literals)
GOOGLE_CLIENT_ID=<from-google>
GOOGLE_CLIENT_SECRET=<from-google>
JWT_SECRET=<auto-generated-64-char-random>
FRONTEND_URL=<project's frontend dev URL>
```

## Execution
Run the project's bootstrap script (`bash agents/setup.sh`), which must read the project/app name,
redirect URI, and output path from the environment/PROFILE rather than hardcoding them.

> **Example — FamilyCall (illustrative, not prescriptive):**
> `project_name=familycall`, `redirect_uri=http://localhost:8080/login/oauth2/code/google`,
> `output_file=/Users/vibhutiraman/Downloads/sheetPreparation/.env`, `FRONTEND_URL=http://localhost:5173`.
> For any other project these all change — derive, don't copy.
